# 🎮 Number Guessing Game

A simple **Number Guessing Game** created using Python. The computer randomly selects a number between **1 and 100**, and the player has to guess it.

## 📌 Features

* Random number generation
* User input for guessing
* Hints for every guess
* Simple and beginner-friendly Python code

## 🛠️ Technologies Used

* **Python 3**
* `random` module

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this project.
3. Open the project folder in VS Code or Terminal.
4. Run the following command:

```bash
python3 guessing_game.py
```

## 🎯 How to Play

* Enter a number between **1 and 100**.
* If your guess is too low, the game will tell you **"Too low!"**
* If your guess is too high, it will tell you **"Too high!"**
* Keep guessing until you find the correct number.
* The game ends when you guess correctly.
